# common — 设备端与服务器端共享层

三端行为一致性的主要手段是**共用同一份定义**，而不是各写一遍。
见 `docs/架构设计/系统总体架构.md §4.2`。

| 文件 | 内容 |
| --- | --- |
| `include/km3/error_code.hpp` | 错误码枚举，与 `通信协议规范.md §六` 一一对应 |
| `include/km3/result.hpp` | 轻量 `Result<T>` / `Status`，实时路径只传错误码不构造字符串 |
| `src/error_code.cpp` | 枚举名序列化（REST 直接输出枚举名） |

新增错误码时，必须先改协议规范，再改这里，并同步 `通信协议规范.md` 的编号表。
