# 独立工具开发期间的现有项目本地回归

下列命令各运行一次，均真实 rc=0；相同标签的 `.json` 保存 argv、开始结束时间与源码
SHA256，`.stdout.log/.stderr.log` 保存完整原始输出。没有修改旧源码修测试。

| 标签 | 实测 |
| --- | --- |
| regression-python-pmp | 457 tests，45.342s，OK |
| regression-python-hwtui | 217 tests，0.342s，OK |
| regression-python-tools | 8 tests，0.343s，OK |
| regression-host-build / regression-host-ctest | build rc=0；17/17，11.52s |
| regression-asan-build / regression-asan-ctest | build rc=0；17/17，11.96s |
| regression-tsan-build / regression-tsan-ctest | build rc=0；17/17，12.17s |
| regression-arm64-build | build rc=0；未执行 ARM64 产物 |

逐个字面命令如下；Python 三组独立并行，C++ 各配置顺序运行：

```sh
python3 -I -m unittest discover -s device/drivers/pmp4010/tools -p '_test_*.py'
python3 -I -m unittest discover -s tools/hwtui -p 'test_*.py'
python3 -I -m unittest discover -s tools/tests -p 'test_*.py'
cmake --build build-host -j4
ctest --test-dir build-host --output-on-failure
cmake --build build-asan -j4
ctest --test-dir build-asan --output-on-failure
cmake --build build-tsan -j4
setarch -R ctest --test-dir build-tsan --output-on-failure
cmake --build build-arm64 -j4
```

冻结核对：每条记录中的 `device/drivers/pmp4010/`、`device/CMakeLists.txt`、
`tools/hwtui/`、`tools/tests/` 文件 SHA256 前后一致；各命令之间这些文件的 SHA256
亦一致。独立 C++ 工具由其它 worker 并行开发，因此其哈希可能变化，不计入旧项目冻结结论。
`__pycache__` 未计入源码哈希。

本轮只完成原项目离线回归和交叉构建；未将其当作独立新工具的验收，也未做硬件验收。
四闸门与三生成器保留到新文件完成后逐个运行。
