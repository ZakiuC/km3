# PMP4010 通讯协议

把厂家的协议原文放这里：对象字典表、报文说明、EDS/DCF 文件、
错误码表、以及任何描述"如何配置这台驱动器"的章节。

建议文件名（便于引用时定位，非强制）：

- `对象字典.md` — 索引、子索引、名称、数据类型、读写、默认值
- `控制字与状态字.md` — 位定义与状态机
- `PDO映射.md` — 默认映射与可改写性
- `EMCY错误码.md`
- `PMP4010.eds` — 若厂家提供，原样放，不要改写

## 注意

- **EDS/DCF 保持原样**：改动会使它的校验失效，且与厂家工具不再一致。
- 若手册是 PDF 且含图，可直接放入，不需要转成 markdown；
  我在提取时会把**文本事实**抄进驱动的 profile，并注明页码或章节。
- 若某些参数只能从厂家上位机软件里看到（手册未列），也请说明，
  那属于"手册外的信息"，我会在驱动的 `README.md` 里显式标注来源。
