# PMP4010 — 机身抬降电机 A

4 台，CANopen，挂主板 can1（CAN 2.0B）。总线已实测拉起：can0 与 can1 均 500000bps。

## 放文件时的第一条注意事项

**操作手册不要覆盖本文件。** 本文件是**索引**（资料清单 + 未确认项）。

协议原文一律放 `协议/` 子目录。
